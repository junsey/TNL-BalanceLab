# ADR 001 · Determinismo del motor

La semilla de texto se codifica en UTF-8 y se reduce a 32 bits por FNV-1a. Cada partida derivada usa el JSON de la pareja [semilla maestra, índice entero] como entrada. Mulberry32 avanza por palabra y conserva su posición en el estado. Los dados usan rechazo para evitar sesgo de módulo. En d100 se consumen decenas, unidades y, con un modificador activo, segundas decenas. Se compara el resultado completo de cada alternativa, tratando 00 como 100.

El hash SHA-256 usa JSON compacto con claves ordenadas por unidades UTF-16 y arrays en su orden original. El registro del ensayo incluye configuración, rondas, valores antes y después, versiones y estado final. Este contrato es técnico y tiene versión propia.

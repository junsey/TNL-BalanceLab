# Reglas pendientes

| Vacío | Procedimiento afectado |
| --- | --- |
| Pifias y tablas de críticos por tipo de daño | Consecuencias de 100 y lesiones de 01 |
| Conexión de un crítico con una defensa que intercepta | Aplicación de la tabla crítica tras defender |
| Tablas de Parada y Bloqueo superados | Consecuencias de daño excedente |
| Capacidades, durabilidad y desgaste por modelo | Parar, bloquear y degradar equipo |
| Desplazamiento canónico al esquivar | El módulo experimental admite rutas explícitas por zona |
| Diskos y equipo con Energía | Activación, capacidad, recarga, cambio de modo y mango |
| Salud fuera del combate | Recuperación y curación |
| Visibilidad y sentidos | Detección, percepción pasiva y oscuridad |
| Armas a distancia, cobertura, sorpresa y efectos especiales | Acciones y efectos correspondientes |

CORE 03 concreta la fórmula de Vulnerabilidad que CORE 04 deja pendiente y desarrolla Salud, Agonía y Muerte como reglas operativas provisionales que CORE 05 todavía enumera como pendientes. CORE 01 y CORE 03 dejan abierta la interacción entre las tablas de consecuencias y las defensas.

El ensayo de blanco pasivo exige declarar desactivadas las consecuencias de pifias, lesiones críticas y desgaste. La tirada 01 conserva el daño de cuarto. El motor táctico acepta tablas experimentales declaradas y emite `UNRESOLVED_RULE` cuando una regla activa requiere un resultado sin definir. El módulo de Energía usa capacidad y recarga configuradas para ensayo. Las cifras canónicas y el procedimiento de activación del Diskos siguen pendientes.
